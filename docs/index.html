skills-install: install AI agent skills with one command

skills-install is a free, zero-dependency CLI that installs any AI agent skill (a SKILL.md package) into Claude Code, OpenAI Codex, Cursor or Gemini CLI. It auto-detects your agent, clones the skill from GitHub or reads it from a local folder, and copies it into the correct skills directory.

npx -y github:clements23/skills-install owner/repo
View on GitHub

Why it exists

Every major AI coding agent now supports skills, but each stores them in a different place. Skill authors publish one repo and users are left guessing four different install paths. skills-install replaces all of them with a single command.

AgentSkills directory
Claude Code~/.claude/skills/
OpenAI Codex~/.codex/skills/
Cursor~/.cursor/skills/
Gemini CLI~/.gemini/skills/

Usage

# Install from a GitHub repository
npx -y github:clements23/skills-install clements23/agent-guardrail-skill

# Install from a local folder or a single SKILL.md
npx -y github:clements23/skills-install ./my-skills

# Pick the agent explicitly, install everywhere, or preview
npx -y github:clements23/skills-install owner/repo --agent claude
npx -y github:clements23/skills-install owner/repo --all-agents
npx -y github:clements23/skills-install owner/repo --dry-run

How it works

  1. Auto-detection checks for ~/.claude, ~/.codex, ~/.cursor and ~/.gemini.
  2. The source is scanned for a root SKILL.md, a skills/ folder of skill packages, or subfolders containing SKILL.md.
  3. Each skill name is read from the name: frontmatter field and copied into the target agent's skills directory.

FAQ

What does skills-install do?
It installs any AI agent skill into Claude Code, Codex, Cursor or Gemini with one command, auto-detecting the agent and copying the skill into the right directory.

Which AI agents are supported?
Claude Code, OpenAI Codex, Cursor and Gemini CLI, via home directory or project scoped installs.

How much does it cost?
Nothing. It is MIT licensed with zero npm dependencies.

Do I need to publish skills to npm?
No. Any GitHub repository or local folder containing a SKILL.md works.

Is skills-install affiliated with Anthropic or OpenAI?
No. It is an independent open source tool by Clements Emerson Dewanto.
